# Citation formats

Every citation carries enough to find the exact words: who, what, where, when, and a link that lands on the
paragraph. Inline numbers [1] map to a numbered Sources list.

## Links
- Gospel Library pages accept a paragraph anchor: append `&id=p<N>#p<N>` (or `?id=p<N>#p<N>` when there is no query
  string) using the paragraph id seen on the fetched page. Scripture verses use the verse number as `p<N>`.
  Open the anchored link once to confirm it lands on the quoted text.
- Use the verified paragraph anchor from the official Gospel Library page. Retrieval tools may count headings and paragraphs differently.
- Keep `lang=eng` unless the requester reads another language.
- Reading Gospel Library in the browser: verses are `.body-block p.verse` (id `p<verse>`); talks, manuals and the
  Handbook are `.body-block p` (and `h2` for headings). Talks from about 2025 on use ids like `p_v31Vo`; cite those
  as-is (`&id=p_v31Vo#p_v31Vo`). Pull many chapters in one browser call and print only the verses you need.
- Pages without paragraph anchors (BYU Speeches, Newsroom, archive.org): link the page and quote enough words to
  find the passage. Conference talks before 1971 are not in Gospel Library; use the archive.org scan of the official
  Conference Report and say it is OCR text.
- Cite Handbook sections by the number on the page you fetched; section numbers shift between editions.
- Prefer the canonical Gospel Library URL over mirrors, PDFs or third-party reposts.
- Write every link in full in the Sources list, one per number; never shorten with an ellipsis or "same page". Use
  a single-paragraph anchor per link (open it to confirm); for a span, link the first paragraph and name the range.

## Formats
- **Scripture**: `Alma 32:21` with a link to the verse. For several verses, give the range and link the first.
  Note the edition only when it matters (e.g. JST, 1830 text).
- **General conference**: Speaker (with title at the time, e.g. Elder/President), "Talk Title," general conference,
  Month Year, paragraph link. Add the magazine printing (Liahona/Ensign, Month Year, page) only when you saw it.
- **General Handbook**: General Handbook, section number and title, link to the section; note "policy, current as
  of <date read>".
- **Manuals and Gospel Topics**: Title of the chapter or entry, manual name, publisher (The Church of Jesus Christ
  of Latter-day Saints), year if shown, link.
- **Magazines**: Author, "Article Title," Magazine, Month Year, page if shown, link.
- **Joseph Smith Papers**: Document title, date, JSP page URL; quote original spelling exactly and say so.
- **Journal articles and books**: Author, "Article," Journal volume, number (year): pages, link or DOI; Author,
  Book Title (Publisher, year), page.
- **Web articles** (FAIR, Scripture Central, Interpreter, Newsroom): Author or organization, "Title," site, date,
  link.

## Quotes
- Quote only text you fetched in this task. Copy it exactly, including archaic spelling and italics where they
  carry meaning. Mark omissions with an ellipsis and never join two passages into one quote.
- A quote inside a talk that quotes someone else is cited as: Original speaker, as quoted by Talk speaker,
  "Title," Month Year. Follow it to the original when you can.
- Paraphrase is fine; a paraphrase still gets a citation.
